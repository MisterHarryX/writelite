# WriteLite 1.0.0 — Windows x64

Локальный помощник для работы с русским текстом. Проверяет орфографию,
пунктуацию, грамматику и стиль на вашем компьютере — без облака и без аккаунта.

- **Версия:** 1.0.0 (`FileVersion 1.0.0.0`, `ProductVersion 1.0.0`)
- **Платформа:** Windows 10/11, x64
- **Дата сборки:** 2026-09-20
- **Установщик:** `WriteLite-Setup-1.0.0.exe`, 815 451 145 байт (778 МБ)
- **После установки:** ~1 389 МБ
- **Цифровая подпись:** отсутствует

## Что изменилось с июльской сборки

Состав функций тот же. Изменилось то, без чего они не работали за пределами
машины разработчика.

**Языковой движок теперь действительно запускается.** LanguageTool 6.4 — это
Java, и в прошлом установщике не было ни одного файла среды выполнения Java.
На компьютере без системной Java движок не стартовал, а приложение молча
переходило на собственную базовую проверку — без сообщения об ошибке. В этот
установщик входит среда OpenJDK 21 (образ `jlink`, ~50 МБ), и сборка релиза
отказывается собираться, если LanguageTool на ней не поднялся.

**Исправлен текст карточки исправления.** Кнопка действия читалась «запятую»
вместо «Добавить запятую»; слово, которого нет в словаре, описывалось как
«не найдено в тексте»; пояснение превратилось в обрывок «…для «{0}».»;
кнопка восстановления читалась «Копировать» вместо «Скопировать».

**Страница «Диагностика» снова показывает данные.** Пятнадцать строк выводили
только подписи — «Поле», «Процесс», «Статус» — без значений.

**Галочка автозапуска в установщике больше не пропадает.** Раньше первый запуск
стирал запись, которую установщик только что создал.

**Не нужен .NET Runtime.** Сборка self-contained.

## Что входит в комплект

Всё работает офлайн, ничего не докачивается при первом запуске.

| Компонент | Версия / описание |
|---|---|
| Языковая модель | WriteLite-Qwen-0.6B-GEC-1.0.1 (база Qwen2.5-0.5B-Instruct, Apache-2.0) |
| Среда запуска модели | llama.cpp, формат GGUF, **только CPU** |
| Движок правил | LanguageTool 6.4 (LGPL 2.1+) |
| Среда выполнения Java | OpenJDK 21 (`jlink`, GPLv2 + Classpath Exception) |
| Среда выполнения .NET | .NET 10, self-contained — отдельная установка не нужна |
| Орфография | Hunspell, словари ru_RU и en_US |
| Лексика | Словари синонимов, антонимов и толкований |

Модель поднимается локальным сервером на `127.0.0.1:8742`, движок правил — на
`127.0.0.1:18081`. Оба слушают только петлевой интерфейс. Наружу текст не уходит.

## Установка

Установщик ставит приложение **в профиль пользователя**
(`%LocalAppData%\Programs\WriteLite`) и **не требует прав администратора**.
Так сделано осознанно: приложение пишет журнал совместимости рядом с собой, а в
`Program Files` такая запись была бы заблокирована.

На странице «Дополнительные задачи»:

- ☐ Создать ярлык на рабочем столе
- ☑ Добавить WriteLite в меню «Пуск»
- ☐ Запускать WriteLite вместе с Windows

Пользовательские данные — настройки, пользовательский словарь, словарные
пакеты, список игнорирования — хранятся отдельно, в `%LocalAppData%\WriteLite`.
**При удалении они не стираются**, если вы явно не ответите «Да» на отдельный
вопрос деинсталлятора.

## Требования

- Windows 10 или 11, x64
- около 1,6 ГБ свободного места на диске
- 8 ГБ ОЗУ рекомендуется: языковая модель резервирует до 5 ГБ

## Известные ограничения

- **Сборка не подписана сертификатом.** Windows SmartScreen покажет
  предупреждение. Сверьте SHA-256 перед установкой.
- **Тихая установка при запущенном приложении завершается кодом 1.**
  Установщик намеренно отказывается работать поверх живой копии. В обычном
  режиме пользователь видит понятное сообщение; для автоматической установки
  закройте WriteLite заранее.
- Модель работает только на CPU. Ускорения на GPU в этой сборке нет.
- Полноценная проверка английского языка ещё в разработке.
