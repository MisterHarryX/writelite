# Первый промпт для Cursor

Открой корневую папку `WriteLite-Starter` в Cursor и отправь агенту этот запрос:

```text
Ты работаешь над Windows-приложением WriteLite на C# и WPF под .NET 10.

Сначала изучи README.md и docs/ARCHITECTURE.md. Не переписывай проект на Electron, Python, WinUI или другой стек.

Задача текущей итерации:
1. Выполни dotnet restore и dotnet build для WriteLite.sln.
2. Исправь все ошибки компиляции, не меняя архитектурную цель.
3. Запусти приложение и проверь сценарий в стандартном Блокноте Windows:
   - WriteLite появляется в системном трее;
   - при фокусе на текстовом поле появляется оранжевый индикатор;
   - индикатор показывает количество замечаний;
   - панель замечаний открывается;
   - одиночное исправление и «Применить все» записывают текст обратно;
   - поля паролей полностью игнорируются.
4. Добавь локальный диагностический файл logs/compatibility.log, но никогда не записывай в него текст пользователя. Разрешены только название процесса, тип UIA-контрола, доступные паттерны, успешность чтения/записи и сообщения исключений.
5. Добавь окно «Диагностика поля», вызываемое из меню трея. Оно должно показывать:
   - имя процесса;
   - ControlType;
   - ClassName;
   - AutomationId;
   - ValuePattern доступен или нет;
   - TextPattern доступен или нет;
   - IsPassword;
   - BoundingRectangle;
   - возможность записи.
6. Не добавляй сетевые API и не подключай AI на этой итерации.
7. После изменений обнови README.md: перечисли, что реально проверено, а что осталось неподтверждённым.

Главный приоритет — стабильный системный прототип и честная диагностика совместимости, а не визуальные улучшения.
```
