# Журнал изменений WriteLite

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Проект использует [семантическое версионирование](https://semver.org/lang/ru/).

## [1.0.0] — 2026-07-25

Первый полный выпуск для Windows. Всё работает офлайн: языковая модель,
движок правил и словари входят в дистрибутив.

### Добавлено

- Локальная проверка русского текста: орфография, пунктуация, грамматика.
- Контекстные правила «-тся / -ться» и «чтобы / что бы».
- Стилистические подсказки с объяснением правила.
- Словари синонимов, антонимов и толкований.
- Менеджер пользовательских слов и список игнорирования.
- Локальная языковая модель WriteLite-Qwen-0.6B-GEC-1.0.1, запуск на CPU через
  llama.cpp; локальный сервер слушает только `127.0.0.1:8742`.
- Движок правил LanguageTool 6.4 в комплекте поставки.
- Проверка в поддерживаемых текстовых полях Windows через UI Automation.
- Одиночное и массовое применение безопасных исправлений.
- Защита URL, email, путей и технических идентификаторов от автозамены.
- Работа без обязательного облачного аккаунта.
- Установщик для Windows x64: установка в профиль пользователя без прав
  администратора, ярлыки, деинсталлятор, обновление поверх предыдущей версии.

### Известные ограничения

- Установщик не подписан цифровым сертификатом.
- Проверка английского и украинского языков в разработке.
- Ускорение на GPU не поддерживается.
