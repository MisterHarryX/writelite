# Журнал изменений WriteLite

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Проект использует [семантическое версионирование](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-20

Сборка для публичного выпуска. Состав функций тот же, что и у сборки 2026-07-25;
изменилось то, без чего она не работала за пределами машины разработчика.

### Исправлено

- В комплект включена среда Java (OpenJDK 21, образ jlink, ~50 МБ).
  Движок правил LanguageTool 6.4 — это Java, и без JVM на компьютере
  он не запускался: проверка молча опускалась до базовой.
- Карточка исправления: кнопка действия снова читается «Добавить запятую»,
  а не «запятую»; отсутствующее слово снова «не найдено в словаре», а не
  «в тексте»; кнопка восстановления снова «Скопировать».
- Страница «Диагностика» снова показывает значения, а не одни подписи.
- Галочка «Запускать WriteLite вместе с Windows» в установщике больше не
  теряется при первом запуске и при обновлении поверх старой версии.

### Изменено

- В свойствах файла теперь заполнены ProductName, ProductVersion, FileVersion
  и издатель; версия объявлена в одном месте (`Directory.Build.props`).
- Установщик называется `WriteLite-Setup-1.0.0.exe`; добавлены отдельные
  пункты для меню «Пуск» и автозапуска, а при удалении — явный вопрос о
  пользовательских данных (по умолчанию данные сохраняются).
- Из поставки убраны сопроводительные ресурсы .NET для языков, которых
  нет в интерфейсе (221 файл).

Подробности и доказательства — в `docs/WRITELITE_1_0_RELEASE_AUDIT.md`.

## [1.0.0-build.2026-07-25] — 2026-07-25

Первый полный выпуск для Windows. Всё работает офлайн: языковая модель,
движок правил и словари входят в дистрибутив.

### Добавлено

- Локальная проверка русского текста: орфография, пунктуация, грамматика.
- Контекстные правила «-тся / -ться» и «чтобы / что бы».
- Стилистические подсказки с объяснением правила.
- Словари синонимов, антонимов и толкований.
- Менеджер пользовательских слов и список игнорирования.
- Локальная языковая модель WriteLite-Qwen-0.6B-GEC-1.0.1, запуск на CPU через
  llama.cpp; локальный сервер слушает только `127.0.0.1:8742`.
- Движок правил LanguageTool 6.4 в комплекте поставки.
- Проверка в поддерживаемых текстовых полях Windows через UI Automation.
- Одиночное и массовое применение безопасных исправлений.
- Защита URL, email, путей и технических идентификаторов от автозамены.
- Работа без обязательного облачного аккаунта.
- Установщик для Windows x64: установка в профиль пользователя без прав
  администратора, ярлыки, деинсталлятор, обновление поверх предыдущей версии.

### Известные ограничения

- Установщик не подписан цифровым сертификатом.
- Проверка английского и украинского языков в разработке.
- Ускорение на GPU не поддерживается.
