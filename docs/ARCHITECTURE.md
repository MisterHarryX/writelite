# Архитектура WriteLite

## Первый вертикальный срез

```text
Windows UI Automation
        │
        ▼
TextFieldMonitor
        │
        ▼
AutomationTextTarget ─── читает ValuePattern/TextPattern
        │
        ▼
ITextAnalyzer
        │
        ▼
RuleBasedAnalyzer
        │
        ▼
TextSnapshot + Issues
        │
        ├── BubbleWindow
        └── SuggestionsWindow
                │
                ▼
        ValuePattern.SetValue
```

## Целевые модули

### 1. WriteLite.Platform.Windows

- UI Automation;
- определение активного поля;
- координаты каретки и поля;
- безопасная запись;
- адаптеры для Win32, WPF, Chromium и Office;
- контроль уровней целостности процессов.

### 2. WriteLite.Language.Core

- токенизация;
- определение языка;
- морфология;
- правила орфографии;
- синтаксическое дерево;
- правила пунктуации;
- поиск перегруженных предложений;
- ранжирование уверенности.

### 3. WriteLite.Language.Data

- SQLite;
- словари RU/EN;
- словоформы;
- исключения;
- устойчивые выражения;
- контекстные пары;
- пользовательский словарь;
- база синонимов.

### 4. WriteLite.AI.Local (реализовано)

- `WriteLite.AI.Contracts` + `WriteLite.AI.Local` + `LocalAiTextProvider`;
- профиль **Lite** (C# engine, без Python, по умолчанию);
- профили Standard/Quality — ONNX pack в `models/writelight-gec/` (fallback на Lite);
- hybrid: rules + spell + LanguageTool + local AI;
- строгая валидация, diff, защита URL/email/путей;
- обучение: каталог `ai/` (mT5-small, synthetic dataset).
См. `docs/ai/architecture.md`.

### 5. WriteLite.App

- системный трей;
- оранжевый индикатор;
- панель исправлений;
- кнопка пера;
- настройки;
- светлая и тёмная темы.

## Принцип безопасности

- поля с `IsPassword=true` полностью игнорируются;
- текст не отправляется в сеть без отдельного согласия;
- локальные правила работают офлайн;
- журнал текста по умолчанию не сохраняется;
- потенциально опасные исправления не применяются автоматически;
- правка содержит уровень уверенности и объяснение.

## План следующих итераций

### Итерация 1 — системный прототип

Текущий репозиторий.

### Итерация 2 — совместимость

- тесты в Notepad, Word, Telegram Desktop, Discord, Chrome, Edge и ChatGPT Desktop;
- диагностика доступных UIA-паттернов;
- журнал только технических метаданных без сохранения текста;
- отдельные стратегии чтения и записи.

### Итерация 3 — орфография

- Hunspell-совместимые словари RU/EN;
- морфологический анализ;
- пользовательский словарь SQLite;
- смешение латинских и кириллических символов;
- раскладка клавиатуры;
- контекстные пары: «компания/кампания» и другие.

### Итерация 4 — профессиональная пунктуация

- разбор предложения на части;
- союзы и союзные слова;
- придаточные конструкции;
- причастные и деепричастные обороты;
- вводные слова;
- несколько допустимых вариантов с разницей смысла;
- отдельная рекомендация разделить перегруженное предложение.

### Итерация 5 — локальный AI

- выбор компактной модели;
- ONNX Runtime или llama.cpp;
- синонимы и перефразирование;
- ограничение изменяемого фрагмента;
- оценка качества и откат.
