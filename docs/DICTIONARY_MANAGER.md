# Dictionary manager status

The current application has a user-dictionary page for adding, removing,
searching and clearing user words. Built-in lexical packs are loaded locally
with schema/license checks and fallback behaviour for missing or damaged packs.

A full install/update/remove/download manager is not implemented in this
release and is therefore not presented as available. Large dictionaries are not
downloaded automatically. User dictionary data remains separate from bundled
resources.
