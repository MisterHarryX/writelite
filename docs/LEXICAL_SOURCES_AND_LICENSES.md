# Источники локального русского словаря

WriteLite поставляет два логически разделённых слоя:

- `writelight-lexical-open.json` — 58 441 русская лемма со словоформами и частью речи. Пакет строится из OpenRussian на закреплённом commit `50e210c4803237779cb562bc1abcea529066031c` и распространяется по CC BY-SA 4.0.
- `writelight-lexical-core.json` — 176 оригинальных справочных статей WriteLite с русскими определениями, примерами, синонимами и антонимами; лицензия CC0 1.0.

Поля перевода и английские статьи отсутствуют. OpenRussian используется как морфологический источник и не выдаётся за полный толковый словарь. При отсутствии русского определения интерфейс честно сообщает об этом.

Полная запись происхождения, SHA-256 каждого исходного CSV, преобразования, права на коммерческое использование и SHA-256 производных артефактов находятся в `resources/lexical/sources.manifest.json`.

## Воспроизведение

```powershell
python .\ai\scripts\build_core_lexical_pack.py
python .\ai\scripts\build_open_lexical_pack.py --cache-dir "$env:TEMP\writelite-openrussian-50e210c"
```

Вторая команда обращается к сети только во время разработки/сборки, проверяет каждый файл до разбора и прекращает работу при несовпадении SHA-256. Готовое приложение словари не скачивает.

## Ограничение по Ожегову

Лицензия, разрешающая WriteLite распространять полный текст современного словаря Ожегова, не подтверждена. Поэтому его статьи не загружены и не входят в release. Код принимает только отдельно приобретённый пользовательский пакет с проверяемыми метаданными прав; наличие непустого поля `license` само по себе не считается разрешением на распространение.
